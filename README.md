# SB Visions Conference Content Website

This is the working codebase for the private SB Visions website prototype.

## What this website uses

- `dist/index.html` contains the words and page structure.
- `dist/styles.css` controls colors, fonts, spacing, and mobile layout.
- `dist/script.js` controls the mobile menu and contact form behavior.
- `dist/assets/` contains the website photos.

This is intentionally a plain HTML, CSS, and JavaScript website. It has no software framework and no package dependencies, which keeps maintenance low and makes it easy for a friend or web professional to understand.

## Start editing in VS Code

1. Open the `sb-visions-prototype` folder in VS Code.
2. Open `dist/index.html` to change wording or section order.
3. Open `dist/styles.css` to change colors, spacing, or layout.
4. Replace images inside `dist/assets/`, keeping the same filenames when you want the page to update automatically.
5. Open `dist/index.html` in a browser to review simple changes.

## Safe editing routine

1. Make one small change.
2. Save the file.
3. Review the desktop and mobile layouts.
4. Confirm the navigation links and contact form still work.
5. Commit the change to GitHub with a short description.
6. Publish the approved version.

## Before the public launch

- Confirm the final company name and replace every use of SB Visions.
- Connect the final domain and business email.
- Replace the placeholder email `hello@sb-visions.com` in `dist/script.js`.
- Choose a real form service so inquiries are stored and delivered reliably.
- Add final portfolio work and client-approved descriptions.
- Confirm service packages and the pricing approach.
- Add privacy and accessibility information appropriate for the business.
- Connect analytics and verify search settings.

## Working rule

The business owner should own the domain, GitHub account, hosting account, analytics account, and business email. Friends and contractors can be added as collaborators without becoming the only people who control those accounts.
